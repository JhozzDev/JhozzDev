## 🚀 Featured Projects

### [Circuit Tool Analyzer](https://github.com/JhozzDev/CircuitToolAnalyzer)
A circuit-analysis application built with **C#, ASP.NET Core, and Blazor**. It accepts circuit data through a REST API and calculates node voltages using nodal analysis and Kirchhoff's Current Law (KCL).

**Focus:** layered architecture, API development, domain modeling, and unit testing.  
*Status: in development; generalized multi-node analysis and persistence are planned.*

### [Detector Engine](https://github.com/JhozzDev/Detector-Engine)
A monitoring prototype that combines configurable rules with **Isolation Forest** anomaly detection. It exposes a FastAPI backend and a Streamlit dashboard for simulated sensor data.

**Focus:** Python, REST APIs, data processing, machine learning, and automated tests.

### [Podcastner](https://github.com/JhozzDev/Podcastner)
A **C# / WPF** desktop application concept for discovering podcasts and supporting language learning through listening practice, saved content, and vocabulary tools.

**Focus:** desktop development, API integration, and application services.

### [Inventory Sales API](https://github.com/JhozzDev/InventarySales_API)
A backend project focused on inventory and sales. Visit the repository for its current implementation and documentation.
